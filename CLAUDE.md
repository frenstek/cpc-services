# CPC Services

Corporate website for CPC Services Pty Ltd -- an airport cleaning company servicing all airports across Australia and New Zealand. Professional marketing site inspired by we-capture.co.nz with additional features.

## Tech Stack

- React 19 + Vite 8 + Tailwind CSS 4
- react-router-dom 7 (multi-page SPA)

## Setup

```bash
git clone https://github.com/kraegeronimo-tech/cpc-services.git
cd cpc-services
npm install
npm run dev
```

## Environment Variables

None required for local development.

## Deployment

```bash
npx vercel --prod --yes
```

**Vercel URL:** https://cpc-services.vercel.app

## Key Notes

- Company: CPC Services Pty Ltd -- services all airports in AU and NZ (cleaning).
- Theme: Corporate professional -- navy #0A1628, blue #2563EB, Inter font.
- Design inspired by We Capture (we-capture.co.nz) with additional edge features.
- Always use Tailwind utility classes -- never raw CSS for spacing/styling.
